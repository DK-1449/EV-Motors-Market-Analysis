# 🚗 EV Motors Market Analysis - Power BI Dashboard

## 📌 Project Overview
This project presents an in-depth **Electric Vehicle (EV) Sales Analysis** across Indian states and manufacturers, using Power BI. It includes interactive dashboards for visualizing trends, top performers, and EV penetration metrics.

## 📂 Project Components
- Cleaned and preprocessed EV dataset
- Interactive visuals (line, bar, pie charts)
- DAX measures for KPIs
- Year-wise, state-wise, and maker-wise filters

---

## 🔧 Tools & Technologies
- Power BI
- Excel
- DAX
- Data Modeling

---

## 📈 Key Features
- Top EV Makers & Sales Comparison
- 2W vs 4W Segmentation
- EV Penetration Rate
- Sales Trends Over Time
- State-level Analysis
- State-wise EV penetration across 35 states
- Top EV makers and their sales performance
- Sales trend over 4 years (2021–2024)
- 2-Wheeler vs 4-Wheeler analysis
- Market penetration rate comparisons

---

## 💡 Insights
- Maharashtra & Karnataka lead in EV sales.
- OLA Electric is the top 2W EV maker.
- EV adoption is growing rapidly year-on-year.
